# Machine Learning cho AI Engineering

Machine Learning là cốt lõi của AI. Module này sẽ dạy bạn cách máy học từ dữ liệu và cách xây dựng hệ thống có thể dự đoán và ra quyết định dựa trên dữ liệu.

## Mục Tiêu Học Tập

Sau khi hoàn thành module này, bạn sẽ có thể:

- Hiểu các khái niệm chính trong machine learning như supervised learning, unsupervised learning, và model evaluation
- Triển khai các thuật toán machine learning bằng Python
- Hiểu khái niệm overfitting, underfitting, và bias-variance tradeoff
- Làm việc với dataset thực tế, bao gồm preprocessing, feature engineering, và model evaluation


## Vì Sao Điều Này Quan Trọng

Machine Learning là nền tảng của các hệ thống AI. Dù là dự đoán kết quả, phân loại dữ liệu, hay xây dựng agent thông minh, thuật toán ML chính là xương sống cho khả năng ra quyết định của AI.

## Chủ Đề Cốt Lõi & Tài Nguyên

### 1. Introduction to Machine Learning

- [Machine Learning – Stanford University (Coursera)](https://www.coursera.org/learn/machine-learning) — **Miễn phí (audit)**
- [Intro to Machine Learning – Udacity](https://www.udacity.com/course/intro-to-machine-learning-with-pytorch--ud188) — **Miễn phí**

Bao gồm:
- Tổng quan về machine learning
- Supervised và unsupervised learning
- Các thuật toán chính: linear regression, logistic regression, decision tree

### 2. Supervised Learning

- [Supervised Learning – Udacity](https://www.udacity.com/course/intro-to-machine-learning-with-pytorch--ud188) — **Miễn phí**
- [Supervised Learning in Python – Kaggle Learn](https://www.kaggle.com/learn/machine-learning) — **Miễn phí**

Bao gồm:
- Bài toán classification và regression
- k-Nearest Neighbors, Support Vector Machines, Decision Trees, Random Forests
- Các chỉ số đánh giá model (accuracy, precision, recall, F1 score)

### 3. Unsupervised Learning

- [Unsupervised Learning – Coursera (University of Washington)](https://www.coursera.org/learn/unsupervised-learning) — **Miễn phí (audit)**
- [Unsupervised Learning Algorithms – GeeksforGeeks](https://www.geeksforgeeks.org/machine-learning-unsupervised-learning/) — **Miễn phí**

Bao gồm:
- Clustering: K-means, Hierarchical Clustering, DBSCAN
- Giảm chiều dữ liệu (dimensionality reduction): PCA, t-SNE

### 4. Model Evaluation & Tuning

- [Model Evaluation – Fast.ai](https://course.fast.ai/) — **Miễn phí**
- [Introduction to Model Evaluation (Kaggle)](https://www.kaggle.com/learn/intro-to-machine-learning) — **Miễn phí**

Bao gồm:
- Cross-validation
- Bias-variance tradeoff
- Hyperparameter tuning dùng GridSearch và RandomSearch
- Kỹ thuật regularization (L1, L2)

### 5. Practical Machine Learning

- [Practical Machine Learning with Python – Udemy](https://www.udemy.com/course/practical-machine-learning-with-python/) — **Trả phí (thường có giảm giá)**
- [Data Science and Machine Learning Bootcamp with R](https://www.udemy.com/course/data-science-and-machine-learning-bootcamp-with-r/) — **Trả phí (thường có giảm giá)**

Bao gồm:
- Làm việc với dataset thực tế
- Làm sạch và tiền xử lý dữ liệu
- Xây dựng pipeline
- Áp dụng thuật toán ML vào bài toán thực tế

## Gợi Ý Thực Hành & Dự Án

- Xây dựng classifier dự đoán mức thu nhập dựa trên dữ liệu census
- Triển khai hệ thống gợi ý (recommender system) dùng collaborative filtering
- Tham gia cuộc thi Kaggle và giải bài toán thực tế

## Checkpoint: Trước Khi Qua Phần Tiếp Theo
Bạn sẽ có thể:

- Xây dựng model machine learning dùng thư viện như Scikit-learn và TensorFlow
- Hiểu khác biệt giữa supervised và unsupervised learning
- Tune model và đánh giá hiệu quả bằng nhiều chỉ số khác nhau
